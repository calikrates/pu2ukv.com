# Código Q

O Código Q é um conjunto de abreviações de três letras padronizadas pela ITU. Cada código pode ser uma **afirmação** ou, seguido de **?**, uma **pergunta**.

> Ex.: `QTH?` = "qual sua localização?" · `QTH Osasco` = "estou em Osasco".

## Os mais usados na faixa

| Código | Significado |
|---|---|
| **QRA** | Nome do operador / da estação |
| **QRB** | Distância entre as estações |
| **QRG** | Frequência exata |
| **QRH** | Sua frequência está variando |
| **QRI** | Tonalidade da emissão (1–3) |
| **QRK** | Inteligibilidade do sinal (1–5) |
| **QRL** | Estou ocupado / frequência em uso |
| **QRM** | Interferência de outras estações |
| **QRN** | Ruído atmosférico / estática |
| **QRO** | Aumentar potência / alta potência |
| **QRP** | Diminuir potência / baixa potência |
| **QRQ** | Transmitir mais rápido |
| **QRS** | Transmitir mais devagar |
| **QRT** | Encerrar transmissão / sair do ar |
| **QRU** | Nada mais para você / tem algo para mim? |
| **QRV** | Estou pronto / à disposição |
| **QRW** | Avise a estação ... que a chamo |
| **QRX** | Aguarde / chamarei novamente às ... |
| **QRZ** | Quem está me chamando? |
| **QSA** | Intensidade do sinal (1–5) |
| **QSB** | Sinal com desvanecimento (fading) |
| **QSD** | Sua manipulação está defeituosa |
| **QSG** | Transmitir ... mensagens de uma vez |
| **QSK** | Break-in: escuto entre os sinais |
| **QSL** | Confirmo recebimento / cartão QSL |
| **QSM** | Repita a última mensagem |
| **QSN** | Ouvi você em ... kHz |
| **QSO** | Comunicado / contato bilateral |
| **QSP** | Retransmitir mensagem para ... |
| **QSR** | Repita sua chamada |
| **QST** | Mensagem geral a todos os amadores |
| **QSU** | Responda nesta frequência |
| **QSV** | Transmita uma série de "V" (ajuste) |
| **QSW** | Vou transmitir em ... kHz |
| **QSX** | Escutarei em ... kHz |
| **QSY** | Mudar de frequência |
| **QSZ** | Transmita cada palavra duas vezes |
| **QTA** | Cancele a mensagem nº ... |
| **QTC** | Tenho ... mensagens para você |
| **QTH** | Localização da estação |
| **QTR** | Hora exata (UTC) |
| **QTU** | Horário de operação da estação |
| **QTX** | Manterei escuta até ... |
| **QUA** | Notícias da estação ... |

## Uso popular no Brasil

| Código | Significado no dia a dia |
|---|---|
| **QAP** | Na escuta / permaneça na frequência (origem aeronáutica) |
| **QSJ** | Dinheiro, valor |

## Escala RST

| | Significa | Escala |
|---|---|---|
| **R** | Legibilidade (*readability*) | 1 a 5 |
| **S** | Intensidade (*strength*) | 1 a 9 |
| **T** | Tom — só em CW (*tone*) | 1 a 9 |

`59` ("cinco nove") é sinal perfeitamente legível e forte. Em CW, `599`.
